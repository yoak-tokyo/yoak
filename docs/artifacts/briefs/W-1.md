## 見た目の正
`docs/artifacts/mocks/b-index.html`（PO が選んだ案B「インデックス」。ブラウザで開いて触れる）。

## 作るもの
- `src/app/artifacts/page.tsx`：一覧。キーワード検索、事業での絞り込み、タグでの絞り込み。新しい順で固定（AD-12）。各行から claude.ai を新しいタブで直接開ける
- 登録：claude.ai のリンク、タイトル、説明、事業（6つから1つ、必須。AD-10）、タグ（自由入力＋よく使うタグの候補。AD-12）

- 詳細ページは作らない（AD-12）
- 部品は `src/components/artifacts/` に置く
- 静的書き出し（`output: "export"`）のままで動くこと。データはブラウザから `/api/artifacts*` を呼んで取る
- 読み込み中・0件・API のエラー（401 はログインが切れた、503 は準備中、ほか）の表示

## API について
- 事業の項目と `GET /api/artifacts/tags` は B-3 が同時に作っている。形は `docs/artifacts/briefs/B-3.md` のとおり（`business` は `Yoak` / `nightbrew` / `nomitai` / `LAMP` / `CaseMatch` / `その他`）。この形を前提に作ってよい
- API を呼ぶ処理は1か所（`src/components/artifacts/api.ts` など）にまとめる
- ローカルで画面と API をつなげて試すには `docs/artifacts/setup.md` の「ローカル開発」（`wrangler dev -c wrangler.local.jsonc`）。B-3 がまだマージされていなければ、事業まわりは API を少し借りて試すか、確かめられなかったと報告に書く

## 触ってよい範囲
`src/app/artifacts/`、`src/components/artifacts/`。サイト全体のヘッダーやフッターへのリンクは足さない（社内向けのページなので）。`src/app/globals.css` を変える必要があれば、変えずに報告に書く。

## やらないこと
- モックにない機能・項目・文言を足さない。迷ったら仮置きせず報告に書く
- worker/・migrations/ は触らない（B-3 の範囲）
