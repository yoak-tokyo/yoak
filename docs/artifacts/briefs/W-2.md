# W-2 指示書：登録者の名前（画面）

決定ログ `docs/artifacts/decisions.md`（AD-16、AD-18）と W-1 の指示書 `docs/artifacts/briefs/W-1.md` を先に読む。
API は B-5 が同時に作っている。形は `docs/artifacts/briefs/B-5.md` の「API の形」のとおりで、それを前提に作ってよい。

## 作るもの
- 一覧の登録者：`author_name` があればそれ、無ければ今までどおりメールの @ より前
- 自分の名前が無いとき（`GET /api/artifacts/me` の `name` が null）：登録の画面のいちばん上に「あなたの名前」の入力欄を出す（必須、30 字まで）。登録するときに先に `PUT /api/artifacts/me` で保存してから登録する。名前があれば欄は出さない
- 欄の見た目は、ほかの入力欄と同じ書き方にする。新しい画面・ボタン・名前を変える入口は作らない（必要そうなら報告に書く）

## 触ってよい範囲
`src/app/artifacts/`、`src/components/artifacts/`。worker/・migrations/ は触らない。

## 完了条件
- `npm run lint`、`npx tsc --noEmit`、`npm run build` が通る
- B-5 がまだマージされていなければ、API の応答を手元で差し替えるなどして、名前あり・名前なし・`author_name` なしの表示を確かめる。B-5 の branch（`feat/B-5-profiles`）がプッシュされていれば、それを手元で合わせて `wrangler dev` で通しで試してもよい
- スマホ幅（390px）とパソコン幅のスクリーンショット（名前の入力欄が出た登録画面、一覧）を PR に貼るか、置き場所を報告に書く
